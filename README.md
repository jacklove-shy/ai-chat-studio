# Forma — AI Chat Studio

一个面向 AI 应用前端岗位的开源作品集项目。Forma 将流式对话、会话管理和模型连接配置放进一张简洁的工作台界面里。

> 当前版本同时提供本地演示模式和 OpenAI 兼容接口接入。无需 API Key 即可体验主要交互。

## 功能

- **流式对话体验**：打字机式演示回复；配置 API 后使用 Server-Sent Events 流式读取模型回复。
- **会话管理**：新建和切换对话，按标题搜索会话，支持 `⌘ K` / `Ctrl K` 快捷键。
- **模型配置**：填写 OpenAI 兼容 API Base URL、模型名称和 API Key。
- **隐私优先的 Key 处理**：Key 只保存在页面内存中，刷新后清除；请求从浏览器直接发往所填服务商。
- **交互细节**：快捷提示、复制回复、错误提示、停止生成、响应式布局和键盘无障碍状态。
- **离线演示**：没有密钥时使用本地模拟回复，不会发起模型请求。

## 快速开始

需要 Node.js 20 或更高版本。

```bash
pnpm install
pnpm dev
```

在浏览器打开 Vite 显示的本地地址即可体验。

## 连接模型

点击底部模型名称 → **配置模型 API**，填写：

1. **API Base URL**：例如 `https://api.openai.com/v1`
2. **模型名称**：例如 `gpt-4o-mini`
3. **API Key**：服务商提供的密钥

此项目通过浏览器直接调用 OpenAI 兼容的 `/chat/completions` 流式接口。部分服务商会限制跨域请求（CORS）；此时需要通过自己的后端代理转发。请勿将个人密钥提交到 Git、分享截图或放进公开部署环境。

## 技术栈

- React 18 + TypeScript
- Vite
- lucide-react
- CSS（响应式布局与动效）

  main.tsx      # 应用入口

## 开发脚本

- `pnpm dev` — 启动本地开发服务器
- `pnpm build` — TypeScript 检查并构建生产静态资源
- `pnpm preview` — 本地预览生产构建
- `pnpm format` — 使用 Prettier 统一代码格式

## 设计说明

Forma 采用暖白色工作台、低对比度边界和克制的紫色强调色。桌面端保留会话导航和上下文侧栏；窄屏下导航折叠为抽屉，消息区成为主要操作区域。演示数据使用中文产品场景，方便直接展示完整对话而无需额外配置。
